## APKTool rebuild reminder for challenge 18

```bash
apktool d app-debug.apk -o decoded
# patch the Smali method gateOpen() so it returns const/4 v0, 0x1
apktool b decoded -o patched-unsigned.apk
zipalign -p -f 4 patched-unsigned.apk patched-aligned.apk
apksigner sign --ks debug.keystore --out patched-signed.apk patched-aligned.apk
adb install -r patched-signed.apk
```

A debug keystore generated by Android Studio can be used for local classroom testing.
