# Challenge List

The CTF contains 18 flags. The app theme is a fictional University of Luxembourg mobile incident-response console for the Security of Mobiles course.

| # | Challenge area | Main skill | Difficulty |
|---|---|---|---|
| 1 | APK entry point | Inspect manifest and launcher activity | Easy |
| 2 | Assets | Decode Base64 from APK assets | Easy |
| 3 | Archive layers | Identify and extract a renamed ZIP file | Easy |
| 4 | Java bytecode | Rebuild shifted strings in jadx | Easy |
| 5 | Deep link | Trigger exported deep link with adb | Medium |
| 6 | Exported activity | Pass a trusted-looking intent extra | Medium |
| 7 | SharedPreferences | Inspect local app key/value storage | Medium |
| 8 | WebView | Inspect local HTML and JavaScript | Medium |
| 9 | Tap sequence | Reverse a simple UI state machine | Medium |
| 10 | ABI gate | Reverse a phrase check | Medium |
| 11 | Network sync | Capture or inspect a diagnostic HTTP header | Hard |
| 12 | Manifest metadata | Decode an application metadata value | Easy |
| 13 | SQLite | Recover a record from app-local database storage | Medium |
| 14 | Logcat | Trigger and read a diagnostic beacon | Medium |
| 15 | Broadcast receiver | Send a crafted broadcast with adb | Medium |
| 16 | Android resources | Reassemble a string-array and apply ROT13 | Easy/Medium |
| 17 | Content provider | Query an exported provider | Medium |
| 18 | Instrumentation | Patch a Smali branch and rebuild the APK | Hard |

Progress is stored locally on the device. A submitted flag is counted only once.
